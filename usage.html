Firebase使用量

Firestoreの読み取り・書き込み・削除の回数を、Google Cloudの監視データ（Cloud Monitoring）から取得して、 無料プラン（Sparkプラン）の1日あたりの上限と比べて表示します。
無料枠の「1日」は太平洋時間（米国）の0時に切り替わります（日本時間では夏時間中は16時、それ以外は17時）。 数値は数分遅れで反映されます。

Google Cloudに接続

使用量の取得には、Firebaseプロジェクト（quiz1-4ffdc）の閲覧権限を持つGoogleアカウントでの認可が必要です （このサイトのログインとは別です）。取得した認可は、このタブを閉じるか約1時間で無効になります。

※「Googleアカウントで接続」を使うには、このファイルの OAUTH_CLIENT_ID を設定してください（下の「初回の設定方法」を参照）。

アクセストークンを直接貼り付ける

gcloud CLI をお持ちの場合は gcloud auth print-access-token で表示されるトークンを貼り付けても取得できます。

初回の設定方法
  1. Google Cloud コンソールでプロジェクト「quiz1-4ffdc」を開き、「APIとサービス → ライブラリ」で Cloud Monitoring API が有効になっているか確認します（無効なら有効化）。
  2. 「APIとサービス → 認証情報」で、OAuth 2.0 クライアントID（Firebaseが自動作成した「Web client (auto created by Google Service)」で可）を開き、 「承認済みのJavaScript生成元」にこのサイトのURL（例: ）を追加して保存します。
  3. そのクライアントIDを usage.html の OAUTH_CLIENT_ID に設定します。
  4. 接続するGoogleアカウントには、プロジェクトの「オーナー」「編集者」「閲覧者」または「モニタリング閲覧者」のいずれかの権限が必要です。
  5. OAuth同意画面が「テスト」状態の場合は、接続するGoogleアカウントをテストユーザーに追加してください。「このアプリはGoogleで確認されていません」と表示された場合は「詳細 → 移動」で続行できます。

無料プラン（Spark）の主な上限

項目 上限 超えた場合
Firestore 読み取り50,000 回/日その日の残り時間は読み取りが失敗します
Firestore 書き込み20,000 回/日その日の残り時間は書き込みが失敗します
Firestore 削除20,000 回/日その日の残り時間は削除が失敗します
Firestore 保存容量1 GiB新しいデータを保存できなくなります
Firestore 送信データ量10 GiB/月その月の残りは通信が失敗します

上限は変更されることがあります。最新の値は Firebaseの料金ページ で確認してください。保存容量・送信データ量はFirebaseコンソールの「Firestore Database → 使用状況」で確認できます。
